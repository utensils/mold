- **Web Create files prints as it makes them.** A **File under** group joins
  the Create controls, between the essentials and Advanced (in the controls
  sheet on phones). A titled print offers its own title as a dashed, removable
  ghost chip; a title that matches an existing collection pre-selects it,
  visibly and clearably, and never creates one. `Add tag…` suggests the
  fleet's tags with counts, the collection picker offers None, every merged
  collection, and an inline **New collection…**, and a mono line previews the
  filename the print will land under. The choice rides one-shots, every batch
  sibling, prepared variations, and a sequence's stitched print, and **Reuse
  settings** restores what a print was actually filed under. The whole group
  hides on a host without `capabilities.gallery.organize`. Settings ▸ Library
  gains **Tag new prints with their title** (on by default, stored in this
  browser).
- **Web downloads are named after the print.** Save / Download now suggests
  `{title-slug}__{model}__s{seed}.{ext}` instead of the raw gallery filename;
  the file on disk is never renamed.
