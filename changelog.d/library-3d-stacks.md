- **A 3-D run is one item in My images.** A text-to-3-D workflow publishes a
  print for every stage, so one object used to leave four unrelated tiles — the
  source picture, its matted and delighted copies, and the mesh. The mesh now
  carries the tile with a marker saying how many assets came with it; **Show the
  N assets** opens the run so every one of them is reachable, and they remain
  ordinary prints you can reuse, export and delete. **Reopen as a workflow** on
  a run's print takes you back to the 3-D Studio with its inputs restored,
  rather than degrading it to a one-shot.
