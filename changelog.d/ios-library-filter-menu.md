- **Library Filter button on iPhone and iPad.** The Library toolbar has a
  Photos-style Filter button with the same choices as the Mac: Favourites,
  media type, In or Not in a Collection, Made from a Source, Has Tags /
  Untagged, orientation, a Model Family submenu with colour dots, the Machine
  choice (moved here from View Options), and Clear Filters. Print Info names a
  print's family and shows its colour.
