- **iPhone Create files a print before it develops.** A capability-gated
  **File under** group joins the Create stack as two 44pt rows under Title:
  **Tags** carries a dashed `{slug} · from title` ghost chip derived from the
  print title (removable, and the removal sticks) plus the tags you added, and
  **Collection** pre-selects — never creates — the collection whose slug
  matches the title, clearable with a single tap. Both open a bottom sheet:
  the tag sheet takes typed names (a leading `#` you typed is dropped, one a
  machine actually reported is not) and suggests the fleet's tags with counts;
  the collection sheet offers None, every merged collection with its count,
  and an inline **New collection…** that only records the name. A mono line
  previews the filename the print will land as, `~title-slug` included. The
  choice rides one shots, every Batch N sibling, and every prepared variation.
  The group hides — and nothing is filed — unless the machine the print is
  routed to advertises `capabilities.gallery.organize`; under **Auto** or
  **Most capable** any reachable machine that can file is enough.
- **iPhone sequences carry a title again.** The chain wire now has a title
  slot, so Sequence output keeps the Title field instead of replacing it with
  a note, and the title, tags, and collection are applied to the stitched
  print the sequence lands in the Library. Intermediate clips are never filed.
- **Settings ▸ Library** gains **Tag new prints with their title**, on by
  default. It is a mirror of a chip you can always see before Generate, so
  turning it off simply stops offering it; prints you already made are
  untouched.
