- **Desktop Create files a print before it develops.** A capability-gated
  **File under** group sits in the Create inspector between the essentials and
  Advanced: a dashed `{slug} · from title` ghost chip derived from the print
  title (removable, and the removal sticks), typed tags with autocomplete over
  every connected machine's tag counts, and a collection row that
  pre-selects — never creates — the collection whose slug matches the title,
  with a picker for the fleet's collections and an inline **New collection…**
  that only records the name. A mono line previews the filename the print will
  land as, `~title-slug` included. The choice rides every request built from
  the form — one shot, each Batch N sibling, each prepared variation, and a
  sequence's stitched print — and **Reuse settings** restores a print's
  recorded filing. Settings ▸ Library gains **Tag new prints with their
  title** (on by default); turning it off changes nothing about prints you
  already made. The group hides entirely on a machine whose
  `capabilities.gallery.organize` is not true.
- **Desktop Save / Export suggest a readable download name.** The file dialog
  now offers `{title-slug}__{model}__s{seed}.{ext}` — `mold-core`'s own
  download grammar — instead of the bare title slug, so two takes of one print
  no longer collide in a Downloads folder. The gallery filename is unchanged.
