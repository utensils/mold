# macOS durable media, H3 distribution, and shape parity

Investigation: 2026-10-05. Source HEAD: `3ba145d9e3692b3ea0d42df3d29edb1ea8650497` (history count 1460). Scope: investigation and reviewed implementation plan; no product implementation or generation runs.

## Evidence and root causes

### 1. Nightly is current, but the embedded engine omits H3

The installed `/Applications/Mold Studio.app/Contents/Info.plist` reports `0.32.1-nightly.1460`, matching the supplied updater screenshot and this checkout's history count. “Native” identifies the app surface; it does not imply stable channel.

`apps/macos/Makefile:engine` invokes `cargo build --release --features metal`. The standalone FFI manifest `apps/macos/rust/mold-macos-ffi/Cargo.toml` exposes only `metal = ["mold-server/metal"]`; no H3 edge exists. `.github/workflows/macos-native-distribution.yml` calls `make signed`, which builds this engine. This is a shipping recipe mismatch, not evidence of an old installed app. The CLI/Nix Metal recipe includes H3.

H3 Metal support already exists. The native app must compose the exact reviewed server set from `crates/mold-server/build_support/h3_server_features.rs:PUBLIC_H3_METAL_SERVER_FEATURES`: H3, private bridge, Metal, MP4, mesh texture/matting/delight, with permitted orthogonal capabilities. Simply adding `h3` to the Makefile is insufficient. Backend support does not establish quality, memory or speed qualification at every resolution/task.

### 2. The retained files exist; the reference UI has no preview path

Read-only requests to the Mac's configured Plato backend showed `minimax_h3.runtime_available=true`, Ref2VA model `runtime_available=true`, and durable-media protocol v2. Recent Ref2VA outputs carry four reference descriptors; their source-media inventories return `available` with four `references` members. One authenticated retained-member GET returned HTTP 200 and 179899 bytes. The exact screenshot print is not identified, so this proves the recent same-model path rather than every archive.

`ReferenceProvenance.generationReference` in `OutputMetadata+Chain.swift` deliberately restores descriptor-only media. Mac `GenerationReferencesGroup.referenceRow` and named camera wells only pass `reference.media.data` to `PictureWell`; no retained reference thumbnail fetch occurs. `ReuseStore+Picture` fetches only `source_image`. The iOS typed-reference wells also render only inline bytes; its ratio picker is a useful reference, but its retained reference preview behavior should not be copied as a complete solution.

### 3. Mac retained authority is too short-lived for normal reuse

`ReuseStore+Release.pending(for:)` requires whole-draft equality. Editing a prompt, seed, size, filing, or target can therefore strand unchanged descriptor references. `referenceRefusal(for:)` then disables Generate, even though the archive still exists. `take(for:)` clears the authority before admission, so a failed admission or a second render also strands those descriptors. iOS `RetainedReuse` retains source authority across presses and uses `RetainedReferenceGuard` to compare reference content, illustrating the narrower contract needed.

The guard also requires all references to be descriptors, so mixtures of newly attached inline media and unchanged retained descriptors cannot use the existing hydration path. Current shared hydration selects all descriptor references as a unit. Support for subset edits requires explicit ordered identity mapping and a server contract audit; it must not be approximated with member counts or positional guessing.

Restart is a separate gap: `DraftPersistence` saves only `DraftDescriptor`, which intentionally omits media, and `ReuseStore` authority exists only in memory. The inspected on-disk draft names Ref2VA but contains no reference descriptors or archive origin. Relaunch therefore cannot restore this retained-media handoff from the current draft file.

### 4. Remote H3 warning has a separate source and a stale-state risk

`PlacementHint` shows `PlacementProbe`'s server response or error. Swift does not consult the embedded Rust engine to decide whether Plato can render. `GeneratePane.selectedModel` reads the chosen host's per-host model listing. Thus missing local H3 should not veto remote H3.

The screenshot's exact warning cannot be reproduced from the current Plato model listing. A read-only placement request built from a recent print and correctly redacted descriptor digests instead reports “MiniMax H3 Ref2VA placement preview is not modeled without staged reference media.” This is a preview limitation, not a generation refusal.

Two concrete client risks need regression tests: `GeneratePane` refreshes placement for draft/model changes but does not explicitly observe target host changes; `PlacementProbe.refresh` leaves the previous answer visible during a new probe, and its generic error catch lacks the post-await cancellation check used by the success path. An obsolete host/error response can therefore remain visible or overwrite the current hint. These are credible mechanisms for the screenshot discrepancy, not proof of its precise sequence.

The disabled Generate button is governed by reference/draft/chain validation, not `placement.reason`. Diagnose and present the actual blocking reason separately from advisory placement text.

### 5. Shape presentation is intentionally text-only on Mac

`ShapeControl.aspectMenu` draws ratio text and a selection checkmark. iOS `AspectRatioIcon` rasterizes the offered dimensions into a template image for native menu labels. This is a presentation gap; `CanvasShape` already shares aspect/size selection semantics.

## Acceptance criteria

- A supported remote H3 host remains usable when this Mac has no local H3 runtime.
- Four retained image references display in correct order with honest loading/failure states; edits and retries never strand unchanged media.
- Removing/replacing a reference cannot revive hidden archive conditioning or hydrate the wrong member.
- Same-host sessions are freshly minted for each exact request; cross-host/multi-output bytes remain bounded and authenticated.
- Nightly and stable native embedded engines expose the reviewed Metal H3 runtime graph; the actual shipped artifact is checked.
- Shapes show proportional outline icons with accessible ratio text and unchanged sizing semantics.
- Unsupported preview/qualification states are distinguished from real submission refusals.
- Relaunch restores a retained recipe through a fresh origin probe; until conditioning is verified, Generate is blocked with a visible explanation. An unavailable origin requires deliberate source reselection, replacement or explicit conditioning discard, and can never silently produce an unconditioned render.

### Required lifecycle details from review

- Keep explicit invalidation for model, generation kind and recipe changes. Changing the target host alone may keep the origin locator for cross-host reuse, but must revalidate the selected target recipe, media contract and permissions. Prompt, seed, shape and filing edits must not discard unchanged typed references. Other retained roles retain their own applicability barriers; reference-only equality must never allow an old mask/audio/identity/source role to follow an incompatible model or recipe. Reset and explicit conditioning discard clear the locator; temporary navigation or Generate view unmount does not. Dismissing an informational error alone must not discard attachments. Add positive and negative tests across those transitions and stale preview/probe completions.
- For close/reopen, persist a versioned, byte-free reuse locator and the safe reference descriptors alongside the draft: origin host UUID/server instance identity, output filename plus available immutable output identity, ordered reference facts/digests, and selected model/recipe. Persist neither member handles, archive internals, credentials, session tokens nor original image/video/audio bytes. On restart, restore a visibly probing state and freshly fetch inventory/metadata from the recorded origin; verify identity and descriptor order/digests before installing any new authority. Never guess an origin or use another machine's archive after deletion, corruption, authentication failure, or server-instance replacement. On unavailable origin or unsupported descriptor version, keep the authored controls and clearly request reselecting the source print or replacing the references. Bound the stored descriptor and test offline/auth/missing archive/reset/migration behavior. Preserve the existing policy that ordinary inline draft media is omitted unless a separate explicit durable draft design is approved.
