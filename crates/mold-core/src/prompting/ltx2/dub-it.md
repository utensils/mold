# LTX-2 Dub-It prompting

Use only for the LTX-2 Dub-It workflow. Treat the input video as the authority
for timing, visible speakers, cuts, and mouth motion. Write concise replacement
speech that fits the observed speaking windows, identify each speaker
consistently, and describe voice, accent, emotion, and delivery without changing
the visual action. Preserve intended ambience unless the user asks to replace it.

Inspect `mold --help` and the selected host's capabilities for the current
Dub-It invocation; do not infer support from the family name alone.
