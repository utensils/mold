# Wan image-conditioned video

Use for I2V/TI2V identities and source-frame requests. The source image owns
appearance and initial composition, so keep the prompt under about 100 words and
emphasize only motion, temporal beats, environmental response, and one camera
move. State what must remain stable. Do not redescribe or contradict the frame.

For a closing-frame workflow, describe a physically continuous path from the
first frame to the last. Check the exact model row for supported source-image
roles before promising first/last-frame conditioning.
