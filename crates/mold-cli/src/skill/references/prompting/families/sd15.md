# SD 1.5 prompting

Manifest family: `sd15`.

Use compact comma-separated concepts, repeat the most important subject early,
and provide a real negative prompt. Keep near the model's native 512-pixel scale
unless the selected profile advertises otherwise. For ControlNet, describe the
intended rendered subject; the control image owns pose, edges, or depth.

```bash
mold run dreamshaper-v8:fp16 \
  "fantasy castle on floating islands, waterfalls, sunrise, wide establishing shot, detailed concept art" \
  --negative-prompt "blurry, low detail, text, watermark, malformed architecture" --seed 555
```
