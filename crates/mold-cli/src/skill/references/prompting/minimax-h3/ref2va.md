# MiniMax H3 Ref2VA

Use only for Ref2VA identities. Name ordered references as `<Picture n>`,
`<Video n>`, and `<Audio n>` in their supplied order. A five-second clip should
normally remain one continuous shot. Keep speech short enough to finish before
the final pose. If a reference video contains a soundtrack, confirm the live
server's ordinal behavior before assigning later audio references; strip
unwanted audio before upload.

Preserve the three-section H3 grammar from the family base guide and state which
traits each reference owns. Do not let one reference silently replace another's
identity, motion, or sound role.
