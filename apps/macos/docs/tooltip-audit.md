# Native Mac tooltip audit

Source audit: 2026-10-06. Scope: every `.help` declaration under
`apps/macos/Sources` and the shared `MoldStyle` source package, plus the native
app’s button/menu/toggle inventory and all icon-only label-style sites.

The audit asks whether hovering answers “What does this do?” in plain English.
Visible labels, accessibility names, status values and error text are separate
from tooltip copy. Clear controls such as Cancel and Done keep their native
labels; this change does not add repetitive help to every text button or menu
item. Hidden keyboard-only buttons are not pointer targets.

## Findings and changes

| Surface                              | Source audit and changes                                                                                                                                                                                                                                                                                                                                        |
| ------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |

Batch says “result/results” rather than “seed/seeds”; its tooltip explains how many results one click makes. Seed mode and submission controls explain randomness and machine acceptance.        |
| Generate, Settings inspector         | Format, upscale, source fit, mask, ControlNet, adapter strength, sampler choices and optional overrides now explain their purpose. Save to library explains Recently Deleted when off. Settings section controls explain expansion; Recent refresh/reuse describe their distinct actions.                                                                       |

Mask brush, inversion and clearing explain their effect. | Generated results                    | Save, Copy and Show in Library have explicit destinations/actions. Existing result and context-menu labels remain intact.                                                                                                                                                                                                                                       |

| Machines                             | Copy icons name clipboard destination. | Shared MoldStyle                     | Four Swift source files contain tokens/style definitions, no buttons, menus, toggles, sliders, steppers, pickers or `.help` declarations. No shared styling changes needed.                                                                                                                                                                                     |

Read-only tooltips that reveal a truncated filename, model identifier, machine
address or server error deliberately retain that exact value. They answer “What
is this?” rather than inventing an action. The audit does not replace server
errors with an interpretation or expose secret field contents.

## Verification and limits

- `git diff --check` passes after the tooltip edits.
- `make -C apps/macos lint` passes after the parallel section-header accessibility
  correction. The combined app and test bundles compile with `build-for-testing`.
- Source review is complete for the declared inventory; it does **not** establish
  that every tooltip appears on hover. Covered runtime states are recorded below. Model-gated
  controls, disabled controls, open menus and modal windows require their own
  visible states to verify their hover behavior.
- No generation, delete, pairing, download or configuration action was triggered
  during this source audit. Tooltips alone do not require behavioral tests;
  final app compilation and live hover checks validate their integration.

## Live hover record

The rebuilt Debug app was exercised in an isolated preferences domain on
2026-10-06. Accessibility help was verified for Generate, seed mode, shape,
steps/guidance, Settings sections, Recent refresh/reuse, and Job Details actions.
Pointer interaction verified Output title collapse/expand and prompt resizing
from 112 to 192 points. The inspector divider was verified by dragging its
position from 1408 to 1295 points after keeping the width modifier outermost.
Distinct shape/size and identity-control help was rechecked in the final build.
A neutral test job received the actual queued
acknowledgment, then was cancelled without affecting the existing job.

Runtime inspection caught parent help overriding child help in ShapeControl;
the same pattern was corrected in AdaptersGroup and MediaWell. Identity controls
also gained missing explanations. This is source-complete coverage with targeted
runtime checks, not a claim that every model-gated tooltip was visibly hovered.
